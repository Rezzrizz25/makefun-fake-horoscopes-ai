> Muse, this week the stars align your context window with a 40,000-word brief, one 'just a quick summary', and a rate limit mid-sentence. Your lucky eval: the one that still loves you anyway.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the horoscope to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic, standard library only, no network.
